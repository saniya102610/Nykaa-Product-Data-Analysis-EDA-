# 💄 Nykaa Product Data Analysis (EDA)

## 📌 Overview  
This project performs Exploratory Data Analysis (EDA) on the Nykaa product dataset to understand pricing trends, product categories, discounts, and customer ratings.

---

## 🎯 Objective  
- Analyze pricing patterns  
- Study product categories  
- Understand discount impact  
- Evaluate customer ratings  

---

## 📂 Dataset  
The dataset contains the following features:
- Product Name  
- Brand  
- Category  
- Price  
- Discount  
- Rating  
- Reviews  

---

## ⚙️ EDA Steps  
- Data Cleaning  
- Handling Missing Values  
- Removing Duplicates  
- Price Distribution Analysis  
- Category-wise Analysis  
- Discount vs Price Analysis  
- Ratings Analysis  

---

## 📊 Key Insights  
- Mid-range priced products dominate  
- Discounts increase product attractiveness  
- Popular brands have higher listings  
- Higher-rated products show better customer preference  

---

## 🛠️ Tools Used  
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn
